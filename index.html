Chemical RAG Knowledge Base

Core Project

An intelligent Q&A system for chemical engineering domain, built with pure Python RAG pipeline. Features domain-specific document chunking, hybrid retrieval, and quantitative evaluation.

  • SDS structured chunking: semantic split by 16 safety data sheet sections
  • Three-way retrieval: BM25 keyword + vector search + CAS number exact match
  • BGE-Reranker-v2-m3 for precision reranking of retrieval results
  • PubChem API integration for real-time chemical property enrichment
  • RAGAS evaluation: Faithfulness 0.85, Answer Relevancy 0.82
  • A/B experiment: optimized RAG vs baseline, 30%+ improvement
